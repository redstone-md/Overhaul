# Iris example fixture provenance

These four shader files are unchanged copies from
https://github.com/IrisShaders/Iris-Example-Shaderpack at commit
`915c67d5f16584d1a1ec1f71b10c4f4af22939e1`.

The upstream LICENSE and the original XorDev source notices are retained.
Only `gbuffers_basic` and `gbuffers_textured` are included. Passing their
translation tests does not establish support for every program in the pack.
